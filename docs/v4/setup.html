04 · Setup, joining and leaving

First-time setup

Page 1 of 5: First-time setup · Tailscale · Joining a session · While playing · Leaving Next: Tailscale →

Listen to this section: Episode 2, Joining and leaving (opens in a new tab)(each opens the Audio guide in a new tab)

Disk space

About 25 GB for Skyrim, our mods and room to spare.

Start with 75 GB free on the drive you use.

Step 1 is crossed out. Everyone in the group already owns Skyrim, so start at step 2.

  1. Get Skyrim on Steam (crossed out: not needed)

    Skyrim Special Edition on Steam. You don't need the Anniversary Upgrade. Already own it? Steam → DLC: disable the Anniversary Upgrade.

  2. Launch Skyrim once

    1. Open the normal Skyrim launcher from Steam.
    2. Choose your display settings.
    3. Reach the main menu, then quit.

    Do this before the cleanup.

  3. Run the cleanup

    1. Get STR-Cleanup-Tools.zip from Kyle's Discord message. Right-click it, choose Extract All and pick a short folder, like your Desktop. This zip is the cleanup only. The patches are a separate file (see Install the Friend Kit patches).
    2. Close Skyrim.
    3. Already used the October 7 kit? In Vortex, remove the mod called STR-Patches before you update the collection (Mods tab, right-click it, Remove). If you see a mod named STR-Friend-Kit-... with a yellow warning triangle, remove that too. It is the old wrapper zip, not the patches.
    4. Double-click START HERE - cleanup.bat and press a key. It backs up the four bundled Creation Club add-ons (the cleanup). It installs no mods.
    5. Read the result. The line "Your game is ready for Skyrim Together." must appear. The window then offers to freeze Skyrim updates (optional; press Y, recommended) and ends with "All done. Close this window."
    6. If it says SOMETHING WENT WRONG, stop and send the host a screenshot.

    Never use Steam's "Verify integrity" afterwards. It puts the add-ons back. If you did, run the .bat again.

  4. Set up Vortex and add the collection

    1. Install Vortex. Sign in.
    2. Settings → Interface → Profile Management: enable it.
    3. Create and enable a profile named STR (for Skyrim Together Reborn). Choose own game settings.
    4. Open our collection on Nexus and click Add collection. Follow its installer choices.

  5. Install the Friend Kit patches

    1. In Vortex, open the Mods tab and click Install From File.
    2. Pick STR-Patches - install this in Vortex.zip from Kyle's message. Pick the zip itself and do not extract it first.
    3. Let it install. Enable it if Vortex asks. Vortex should show one new mod called STR-Patches. If Vortex instead shows a mod named STR-Friend-Kit-... with a yellow warning triangle, remove it. It is the wrapper, not the patches.

    Everyone needs both plugins in it before a shared session. They change some perks (Skills says how). The three race plugins come with the collection and are Required: they give High Elves and Redguards their vanilla racial power back, Wood Elves a new one (Hunter's Mark), stop racial goals being shared with the party and lock two powers (Races says how).

  6. Enable plugins

    1. In Vortex, open the Plugins view.
    2. Enable these plugins:
      • SkyrimTogether.esp, SkyrimTogetherQuestPatches.esp, MysticismMagic.esp, better vanilla perks.esp, STR-HeldPerks-Lock.esp, STR-QuietHunter.esp, Imperious - Races of Skyrim.esp, STR-RaceFallback-HighElf-Redguard.esp, STR-WoodElf-HuntersMark.esp, STR-FiveRaces-Stability.esp, Cathedral Weathers.esp, RandomDragonsNoMore.esl, SimplestSurvival.esp, STR-SimplestSurvival-Needs30min.esp, notice board.esp, VampireAttacksRestored.esp, STR-VampireCadence.esp, ElysiumEstate.esp, Skyrim Trading Posts.esp, Skyrim Bandit Expansion.esp and Skyshards.esp.
    3. Also enable the plugins of any Optional mods you installed. Harborwatch's plugin is SToghouse.esp.

  7. Copy the host's load order

    Do this after the collection and the patches are installed and ticked, and before you start Skyrim Together. It is a separate download, STR-Load-Order.zip, with its own READ ME.

    1. In Vortex, open the Plugins view. Click the top-bar button that says Autosort Enabled once. It must now say Autosort Disabled. Never click Sort Now.
    2. Close Vortex completely, also from its icon by the clock.
    3. Press the Windows key + R, paste %LOCALAPPDATA%\Skyrim Special Edition and press Enter. Copy plugins.txt and loadorder.txt from there into a new Desktop folder called old load order, as a backup.
    4. Extract STR-Load-Order.zip. Copy its plugins.txt and loadorder.txt into that Skyrim Special Edition folder and replace the two files.
    5. Double-click Check load order.bat. The last line must say RESULT: MATCH. If it says DIFFERENT, do not start the game: redo the steps, or send the host a screenshot.
    6. Open Vortex again. It must still say Autosort Disabled. Run Check load order.bat once more before every session.

    Why: the server checks that you have the same plugins, not their order. Two PCs with the same 44 plugins can load them in a different order, and then a player can look frozen on someone else's screen. Vortex sorts each PC by itself, so the host's exact order is copied in. Install, update or remove no mods without telling the host, because that can change the order.

  8. Tailscale

    Do steps 1 and 2 before game day. Every click is on the Tailscale page.

    1. Install Tailscale from tailscale.com/download/windows.
    2. Sign in with a personal Google, Microsoft, Apple or GitHub account.
    3. On game day the host sends your join link privately. Open it and accept the share.

  9. First join

    1. Make a desktop shortcut to SkyrimTogether.exe in Skyrim Special Edition\Data\SkyrimTogetherReborn. Always start the game from it. Steam's Play button starts the single-player game.
    2. Double-click the shortcut. Finish Helgen Express offline. Tip: on the starting screen, each click on a choice changes it. Keep clicking a choice until it shows the one you want.
    3. Save outside Helgen before connecting.
    4. Setup is complete when Skyrim Together reaches the main menu and your character is saved outside Helgen. Then follow Joining a session.
