04 · Setup, joining and leaving

First-time setup

Page 1 of 5: First-time setup · Tailscale · Joining a session · While playing · Leaving Next: Tailscale →

Listen to this section: Episode 2, Joining and leaving (opens in a new tab)(each opens the Audio guide in a new tab)

Revision 7 is the live collection. Our Nexus collection page has it.

Disk space

About 25 GB for Skyrim, our mods and room to spare.

Start with 75 GB free on the drive you use.

Step 1 is crossed out. Everyone in the group already owns Skyrim, so start at step 2.

  1. Get Skyrim on Steam (crossed out: not needed)

    Skyrim Special Edition on Steam. You don't need the Anniversary Upgrade. Already own it? Steam → DLC: disable the Anniversary Upgrade.

  2. Launch Skyrim once

    1. Open the normal Skyrim launcher from Steam.
    2. Choose your display settings.
    3. Reach the main menu, then quit.

    Do this before the cleanup.

  3. Run the Friend Kit

    1. Get the Friend Kit zip (October 6) from Kyle's Discord message. Right-click it, choose Extract All and pick a short folder, like your Desktop.
    2. Close Skyrim.
    3. Double-click START HERE - double-click me.bat and press a key. It makes STR-Patches.zip in that folder, then backs up the four bundled Creation Club add-ons (the cleanup).
    4. Read the result. It must end with "Your game is ready for Skyrim Together." When it offers to freeze Skyrim updates, press Y (recommended).
    5. If it says SOMETHING WENT WRONG, stop and send the host a screenshot.

    Never use Steam's "Verify integrity" afterwards. It puts the add-ons back. If you did, run the .bat again.

  4. Set up Vortex and add the collection

    1. Install Vortex. Sign in.
    2. Settings → Interface → Profile Management: enable it.
    3. Create and enable a profile named STR (for Skyrim Together Reborn). Choose own game settings.
    4. Open our collection on Nexus and click Add collection. Follow its installer choices.

  5. Install the Friend Kit patches

    1. In Vortex, open the Mods tab and click Install From File.
    2. Pick STR-Patches.zip from your Friend Kit folder. Not there? Double-click the START HERE .bat again.
    3. Let it install. Enable it if Vortex asks.

    Everyone needs every plugin in it before a shared session. The perk plugins change some perks (Skills says how). The race plugins give High Elves and Redguards their vanilla racial power back and Wood Elves a new one, Hunter's Mark (Races says how).

  6. Enable plugins

    1. In Vortex, open the Plugins view.
    2. Enable the plugins of the revision the host names:
      • Revision 7, the live collection: SkyrimTogether.esp, SkyrimTogetherQuestPatches.esp, MysticismMagic.esp, better vanilla perks.esp, STR-HeldPerks-Lock.esp, STR-QuietHunter.esp, Imperious - Races of Skyrim.esp, STR-RaceFallback-HighElf-Redguard.esp, STR-WoodElf-HuntersMark.esp, Cathedral Weathers.esp, RandomDragonsNoMore.esl, SimplestSurvival.esp, STR-SimplestSurvival-Needs30min.esp, notice board.esp, VampireAttacksRestored.esp, STR-VampireCadence.esp, ElysiumEstate.esp, Skyrim Trading Posts.esp, Skyrim Bandit Expansion.esp and Skyshards.esp.
      • Revision 6, the older collection: SkyrimTogether.esp, SkyrimTogetherQuestPatches.esp, MysticismMagic.esp, better vanilla perks.esp and Imperious - Races of Skyrim.esp.
    3. Also enable the plugins of any Optional mods you installed. Harborwatch's plugin is SToghouse.esp.

  7. Tailscale

    Do steps 1 and 2 before game day. Every click is on the Tailscale page.

    1. Install Tailscale from tailscale.com/download/windows.
    2. Sign in with a personal Google, Microsoft, Apple or GitHub account.
    3. On game day the host sends your join link privately. Open it and accept the share.

  8. First join

    1. Make a desktop shortcut to SkyrimTogether.exe in Skyrim Special Edition\Data\SkyrimTogetherReborn. Always start the game from it. Steam's Play button starts the single-player game.
    2. Double-click the shortcut. Finish Helgen Express offline. Tip: on the starting screen, each click on a choice changes it. Keep clicking a choice until it shows the one you want.
    3. Save outside Helgen before connecting.
    4. Setup is complete when Skyrim Together reaches the main menu and your character is saved outside Helgen. Then follow Joining a session.
