First-time setup

Follow our Nexus collection page for installer choices.
StepSingle playerCo-op
Get Skyrim on SteamSkyrim Special Edition on SteamSpecial Edition. You don't need the Anniversary Upgrade. Already own it? Steam → DLC: disable the Anniversary Upgrade.
Free disk spaceSkyrim aloneFresh setup: allow 25 GB. Skyrim already installed: allow 5 GB extra. Also keep 50 GB free on each drive you use. Everything on one drive? Start with 75 GB free, or 55 GB if you own the game. Downloads can live on another drive. These are planning budgets, not measured peaks. Big game updates may need more. GB here is decimal; Windows may label it GiB.
Disk space we measuredSkyrim aloneOn the host PC, the game and its four bundled add-ons use 16.09 GB. The 19 unpacked mods use 0.65 GB. Their kept download files use 0.23 GB. Mods add about 0.88 GB to an existing game. Revision 7 additions are not measured yet: Cathedral Weathers (about 100 MB to download), Sounds of Skyrim (about 21 MB) and the gear packs.
Open the normal Skyrim launcher onceChoose display settings before playingChoose display settings. Reach the main menu, then quit. Do this before the cleanup below.
Run the cleanup kitNothing to doNexus → Friend Kit: Download ZIP, then Extract All. Close Skyrim. Run the Creation Club cleanup. Read its result and README before continuing. It backs up the four bundled Creation Club add-ons. Never use Steam's "Verify integrity" afterwards.
Set up VortexOptionalInstall Vortex. Sign in. Settings → Interface → Profile Management: enable it. Create and enable an STR profile. Choose own game settings.
Add our mod collectionOptional, one at a timeOn Nexus, click Add collection. Follow the listed installer choices.
Enable five pluginsNot neededIn Vortex's Plugins view, enable: SkyrimTogether.esp; SkyrimTogetherQuestPatches.esp; MysticismMagic.esp; better vanilla perks.esp; Imperious - Races of Skyrim.esp.
Launch the co-op gameSteam's Play buttonDouble-click your configured SkyrimTogether.exe shortcut. Steam's Play button starts the single-player game.
Save your new characterPlay through HelgenFinish Helgen Express offline. Save outside before connecting.
Check setup is completeThe main menu loadsSkyrim Together reaches the main menu. Your character is saved outside Helgen.
