Leaving

Leaving, now or later

Save. Disconnect. Quit.

Save if possible (Esc → Save). Let it finish. Press F2, choose Disconnect, then Proceed. Quit the game (Esc → System → Quit). If you have a moment, step somewhere safe first. Quitting may still crash; no fix is proven.

Unsaved progress may be lost. Tell the group later; no recap needed. Short break: pause quests until everyone returns. Done tonight: save and stop this campaign. Resume together next session.
