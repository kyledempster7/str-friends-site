Skills and races

Build your character

Eighteen skills, no fixed classes. Better Vanilla Perks changes trees; Imperious replaces racial packages. Every race learns every skill.

Use our shared collection

Install the agreed revision. Mentioned mods are not automatically approved.

Read changed perk tooltips before spending points.

Real life comes first

I have to go NOW

Save. Disconnect. Go.

Save if possible. Let it finish. Press F2, choose Disconnect, then Proceed. Quit the game. Quitting may still crash; no fix is proven.

Unsaved progress may be lost. Tell the group later; no recap required.

F2 means F two. This party's exit rehearsal is not tested yet.
